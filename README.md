## Быстрый запуск на своём компьютере (для теста)

1. **Создайте бота:** в Telegram откройте @BotFather → `/newbot` → получите токен.
2. **Установите Python 3.11+** с https://www.python.org/downloads/ (на Windows — галочка «Add Python to PATH»).
3. В папке проекта выполните: `pip install -r requirements.txt`
4. Скопируйте `.env.example` в `.env` и впишите токен (или задайте переменную `BOT_TOKEN`).
5. Запустите: `python bot.py`

**Чтобы бот работал круглосуточно — см. `DEPLOY.md`** (пошаговая инструкция для сервера, Docker).

## Перед публикацией на GitHub

В репозиторий можно добавлять исходный код и `.env.example`, но **никогда не загружайте файл `.env` с настоящим `BOT_TOKEN`**. Файл `.gitignore` в проекте уже исключает `.env`, локальную базу данных и временные файлы Python.

## Render: запуск как Web Service

Проект умеет работать в двух режимах, и выбор задаётся **Start Command**:

| Режим | Start Command | Что это |
|---|---|---|
| 🌐 Браузерная игра (solo) | `python solo.py` | Полная игра «человек против ИИ» прямо на странице сервиса. Токен не нужен. |
| 📱 Telegram-бот | `python bot.py` | Классический режим: игра в Telegram, веб-страница показывает статус. Нужен `BOT_TOKEN`. |

**Браузерная игра:**

1. Загрузите проект в GitHub и в Render создайте **New → Web Service**, подключив репозиторий (runtime **Python 3** или **Docker**).
2. Start Command: `python solo.py` — приложение слушает порт из переменной `PORT` (Render задаёт её сам).
3. Откройте URL сервиса — играется прямо там.

**Telegram-бот:**

1. Runtime **Docker** — в корне проекта уже есть `Dockerfile`.
2. В переменных окружения Render задайте `BOT_TOKEN` (секрет от @BotFather). Не добавляйте настоящий токен в GitHub.
3. Чтобы сохранения SQLite переживали перезапуски, подключите постоянный диск с mount path `/data`. Контейнер уже использует `/data/civ.db`.
4. После Deploy откройте URL сервиса: там будет страница статуса. Чтобы играть, напишите Telegram-боту `/start`.

⚠️ В режиме solo партия хранится в файле `solo_save.json` рядом с кодом; на бесплатном Render он стирается при перезапуске (партию можно сохранить кнопкой 💾 и вернуть через `SOLO_SAVE`/загрузку). Для постоянной партии подключите диск и укажите путь, например `SOLO_SAVE=/data/solo_save.json`.

На бесплатном Web Service Render может усыпить приложение после периода без входящих HTTP-запросов, а локальные файлы могут пропасть при перезапуске. Для постоянно работающего бота и сохранения партий проверьте платный тариф и постоянный диск.

## Как играть

1. Добавьте бота в группу (или играйте с ним один в личке).
2. `/newgame` → остальные `/join` (или `/addai 2` — добавить компьютерных соперников) → создатель `/begin`.
3. Каждый пишет `/menu`: Юниты → Поселенец → «Основать город».
4. В городе выберите, что строить; в «Науке» — что изучать.
5. «Завершить ход». Ход меняется, когда все готовы или по таймеру.
6. `/rules` — правила, `/map` — карта картинкой.

## Что есть в игре

- **Туман войны** и карта картинкой 🖼 (границы, города, юниты, подписи).
- **Города и культура:** здания (амбар, библиотека, стены, рынок, мастерская, храм), чудеса света (по одному на мир),
  культура расширяет границы; в чужие границы нельзя входить в мире.
- **Технологии:** 11 штук по дереву.
- **Юниты:** поселенец, рабочий, разведчик, воин, лучник, всадник, мечник, катапульта. Укрепление, фермы 🌽 и шахты 🪨.
- **Золото:** докупка производства.
- **Дипломатия:** война/мир между игроками.
- **Города-государства** 🏯: дарите золото, становитесь союзником и получайте бонусы — или захватывайте.
- **Ресурсы:** 🐎 лошади (нужны Всадникам), 🔩 железо (Мечникам и Катапультам), 💎 самоцветы. Ресурс должен лежать в вашей земле или рядом с вашим городом; в меню строительства бот подскажет, чего не хватает.
- **Дороги** 🛤 (технология «Колесо»): движение по дорогам втрое дешевле; город, соединённый дорогой со столицей, даёт +2💰 за ход.
- **Религия** 🕊: города копят веру, храм даёт больше; основав религию с выбранным бонусом, вы видите, как она сама распространяется по соседним городам.
- **Корабли** ⛵ («Мореплавание»): галера перевозит 2 юнита через воду. Компьютерные игроки сами строят галеры и заселяют другие острова.
- **Варвары** ⚫ и **селения** 🛖.
- **Компьютерные игроки** 🤖: `/addai` (можно играть в одиночку против ИИ), рабочим и разведчикам — кнопка «Автоматически».
- **Сложность ИИ:** `/difficulty лёгкий|обычный|трудный` (трудный ИИ агрессивнее и получает +30% к экономике).
- **Уровни городов:** Деревня → Город → Мегаполис с бонусами; чудеса строятся в городах с населением от 3.
- **Подсказки** 💡 для новичков в меню (`/hints` — выключить).
- **Уведомления:** бот упоминает игроков в начале хода и напоминает перед его концом.
- **Победа:** господство, научная победа или очки после 60 хода.

## Веб-интерфейс (Mini App) — в духе Civilization 6

Карта `/play` в Telegram — теперь полноценный игровой экран:

- **Верхняя панель**: ход, 💰 золото с доходом, 🔬 наука и текущее исследование с прогрессом, 🕊 вера, ⭐ очки, стратегические ресурсы.
- **Карта**: туман войны, цветные границы, дороги, ресурсы и улучшения, полосы HP юнитов; перетаскивание, щипок/колесо для масштаба, тап — перемещение по маршруту, красная подсветка — атаки.
- **Панель юнита**: основать город, ферма/шахта/дорога, укрепиться, 🤖 автомат, распустить; у миссионера — проповедь.
- **Экран города**: доходы 🌾⚙️💰, рост населения, производство (юниты/здания/чудеса), покупка за золото, обстрел города.
- **Экраны**: технологии с деревом требований, дипломатия (война/мир, города-государства, подарки), религия, «🏆 прогресс побед», советы «💡», события хода, справка, «⚙ настройки».
- **🎯 Дальний бой**: лучник и катапульта стреляют на 2 клетки без ответа; город обстреливает врага раз в ход — как в Civ 6, города берутся только вблизи. В подтверждении атаки — прогноз урона.
- **🏕 Лагеря варваров**: рейдеры приходят волнами из лагерей; разорение лагеря даёт +20💰.
- **Миникарта** с рамкой обзора (тап — перемещение камеры), плавная анимация перемещения юнитов.
- **Управление**: кнопка ➡️ — следующий юнит; клавиатура: стрелки/WASD — движение, N — следующий юнит, Enter — конец хода, H — к столице, +/− — масштаб; у рабочего зелёным подсвечены клетки для ферм/шахт (тап — дойти и улучшить).

Кнопки дальнего боя добавлены и в Telegram-меню (юнит → «🎯 Обстрелять», город → «🎯 Обстрел из города»).

## Одиночный режим в браузере (без Telegram)

`python solo.py` — игра против ИИ прямо в браузере (порт из переменной `PORT`, по умолчанию 8080).
Партия сохраняется в `solo_save.json`. Удобно для примерки игры или как отдельная веб-версия
на Render/VPS: тот же интерфейс, авторизация Telegram не нужна.

Проверка всего потока (нужен запущенный `solo.py`): `python test_solo.py`.

## Настройки (переменные окружения или файл `.env`)

- `BOT_TOKEN` — токен бота (обязательно)
- `TURN_HOURS` — длительность хода в часах (по умолчанию 24; для теста `0.05`)
- `DB_PATH` — файл базы данных (по умолчанию `civ.db`)

## Файлы

- `engine.py` — правила игры, не зависит от Telegram
- `bot.py` — Telegram-часть: команды, кнопки, таймер
- `ai.py` — компьютерные игроки и автоматизация юнитов
- `hints.py` — подсказки новичкам
- `mapimg.py` — рисует карту картинкой (нужен Pillow; без него бот покажет карту эмодзи)
- `webapi.py` — HTTP API Mini App и одиночного режима
- `solo.py` — одиночная игра в браузере против ИИ (без Telegram)
- `test_solo.py` — автоматический прогон solo-режима через HTTP
- `tools/smoke.js` — jsdom-смоук фронтенда (перед запуском: `cd tools && npm i`);
  `node_modules` не хранится в репозитории
- `Dockerfile`, `docker-compose.yml`, `.env.example`, `civ-bot.service`, `DEPLOY.md` — запуск на сервере
