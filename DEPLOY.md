# Как запустить бота на сервере (чтобы работал круглосуточно)

Пока бот запущен на вашем компьютере, он работает только при включённом компьютере.
Чтобы игра шла постоянно, бот запускают на арендованном сервере (VPS).

## Что понадобится
- **VPS с Ubuntu 22.04 или 24.04.** Хватит самого дешёвого тарифа (1 ядро, 1 ГБ памяти).
  Обычно это несколько евро/долларов в месяц у любого хостинг-провайдера.
- **Токен бота** от @BotFather (`/newbot`).
- Программа для подключения: на Windows 10/11, Mac и Linux достаточно встроенного
  терминала (PowerShell / Terminal).

## Способ 1 (рекомендую): Docker

**1. Подключитесь к серверу.** Провайдер даст IP-адрес и пароль. В терминале:

    ssh root@IP_АДРЕС

**2. Установите Docker** (одна команда):

    curl -fsSL https://get.docker.com | sh

**3. Загрузите папку с ботом.** Откройте *второе* окно терминала на своём компьютере,
перейдите в папку, где лежит папка `civ_bot`, и выполните:

    scp -r civ_bot root@IP_АДРЕС:/opt/

**4. Впишите токен.** Вернитесь в окно с сервером:

    cd /opt/civ_bot
    cp .env.example .env
    nano .env

Замените `сюда_вставьте_токен` на ваш токен. Сохранить: `Ctrl+O`, `Enter`, выйти: `Ctrl+X`.

**5. Запустите:**

    docker compose up -d --build

Первый запуск занимает пару минут. Дальше бот сам поднимается после сбоев и
перезагрузок сервера.

**6. Проверьте.** Посмотреть, что происходит:

    docker compose logs -f

(выйти из просмотра: `Ctrl+C`). Напишите боту `/start` в Telegram — он должен ответить.

## Повседневные команды (в папке /opt/civ_bot)

| Что сделать | Команда |
|---|---|
| Посмотреть журнал | `docker compose logs -f` |
| Перезапустить | `docker compose restart` |
| Остановить | `docker compose down` |
| Обновить бота | загрузить новые файлы (`scp`, как в шаге 3), затем `docker compose up -d --build` |

Все партии лежат в файле `data/civ.db`. Для резервной копии просто скопируйте его
(`scp root@IP_АДРЕС:/opt/civ_bot/data/civ.db .`).

## Способ 2: без Docker (systemd)

    apt update && apt install -y python3-venv fonts-dejavu-core
    cd /opt/civ_bot
    python3 -m venv venv
    venv/bin/pip install -r requirements.txt
    cp .env.example .env && nano .env          # вписать токен
    cp civ-bot.service /etc/systemd/system/
    systemctl daemon-reload
    systemctl enable --now civ-bot

Журнал: `journalctl -u civ-bot -f`. Перезапуск: `systemctl restart civ-bot`.

## Важно
- **Токен — секрет.** Не отправляйте его в чаты и не публикуйте. Если он утёк, в @BotFather
  выполните `/revoke` и получите новый.
- Одна группа = одна независимая игра. Бот можно добавить в несколько групп.
- После смены версии игры (например, обновления с первой версии) старые партии
  могут быть несовместимы: напишите в чате `/newgame`.
- Длительность хода меняется переменной `TURN_HOURS` в файле `.env`
  (после правки: `docker compose up -d`).
